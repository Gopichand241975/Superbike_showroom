# VelocityMoto

VelocityMoto is a premium pre-owned superbike marketplace website for motorcycle enthusiasts in India.

## Project Overview

This project is a static website for a premium pre-owned superbike showroom. It includes:

- Hero section with premium motorcycle branding
- Inventory and category sections
- Superbike listings with filters
- Why choose us / trust and service features
- Contact form and lead capture design
- Floating WhatsApp button and back-to-top button

## Tech Stack

- HTML
- CSS
- JavaScript

## Local Setup

Open `index.html` in a browser, or use a local web server:

```bash
python -m http.server 8000
```

Then visit:

https://gopichand241975.github.io/Superbike_showroom/
